# 🐩 강몽실 공주 건강수첩

반려견의 건강을 한 곳에서 기록·관리하는 무료 웹앱입니다. 설치 없이 브라우저에서 바로 사용하며, 입력한 데이터는 **본인 브라우저에만 저장**됩니다(서버 전송 없음).

👉 **바로 사용하기**: https://ssujiniad-wq.github.io/mongsil-care/

## 기능
- **기본 정보** — 견종, 생년월일/나이 자동계산, 체중, 알러지/기왕력
- **림프절 모니터링** — 좌·우 하악 림프절 크기(mm), 대칭·단단함·통증·가동성 촉진 체크, 추이 그래프
- **일일 컨디션** — 식욕·활동량·배변 30초 입력
- **체중** — 기록 + 추이 그래프
- **바크먼트 세션 로그** — 날짜·운동 내용·컨디션
- **병원 방문 기록** — 진단·처방·다음 방문일 D-day
- **정기 관리** — 예방접종·심장사상충·스케일링·미용, 예정일 D-day 자동
- **응급 판단 기준** — 즉시 병원 가야 하는 증상 체크리스트
- **백업** — JSON 내보내기/불러오기로 다른 기기로 이전 가능

## 사용 방법
브라우저에서 위 링크를 열면 끝입니다. 폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 프라이버시
모든 데이터는 사용자의 브라우저 `localStorage`에만 저장됩니다. 외부 서버로 전송되거나 수집되지 않습니다.

## 면책
응급 체크리스트 등은 참고용이며 수의사의 진단을 대체하지 않습니다.
